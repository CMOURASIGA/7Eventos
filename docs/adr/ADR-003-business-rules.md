# ADR-003-business-rules - Regras críticas centralizadas

**Status:** ACCEPTED

## Decisão
Conflito de reserva, capacidade, complexidade e demais regras críticas não devem ficar espalhadas em componentes de UI.

## Motivo
Melhora consistência, testes e manutenção.

## Consequência
Implementações futuras devem respeitar esta decisão. Mudança exige novo ADR que substitua explicitamente este registro.
