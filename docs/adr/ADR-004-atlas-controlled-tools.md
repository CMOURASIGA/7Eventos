# ADR-004-atlas-controlled-tools - Atlas usa funções controladas

**Status:** ACCEPTED

## Decisão
Atlas não altera diretamente dados críticos; ações passam por tools, autorização, domínio e confirmação quando aplicável.

## Motivo
Mantém segurança e rastreabilidade.

## Consequência
Implementações futuras devem respeitar esta decisão. Mudança exige novo ADR que substitua explicitamente este registro.
