# Atlas - Segurança

- Nunca acessar dados de outra empresa.
- Nunca usar IA para contornar autorização.
- Nunca entregar credenciais ao modelo.
- Não persistir conteúdo sensível sem necessidade.
- Alterações críticas exigem confirmação humana explícita.
- Ações estruturadas relevantes devem ser auditáveis.
- Respostas devem deixar claro quando não existem dados suficientes.
