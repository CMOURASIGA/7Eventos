# Atlas - Contexto

Atlas poderá consultar somente dados autorizados e necessários à pergunta: evento, sessões, espaço, reservas, planejamento, checklist, complexidade, orçamento/financeiro, fornecedores, equipe, cronograma, participantes, credenciamento, documentos, auditoria e histórico.

## Controle de tokens
- Enviar somente contexto necessário.
- Resumir históricos longos.
- Preferir consultas estruturadas.
- Nunca enviar o banco inteiro.
- Limitar documentos ao necessário.
- Controlar tamanho de conversas.
- Medir uso de tokens quando a API disponibilizar.
