# Atlas - Tools

Toda ação estruturada de Atlas deve passar por função controlada e pelo serviço de domínio.

## Categorias previstas
- consultas de situação
- resumo do evento
- identificação de pendências e riscos
- proposta de próxima ação
- preparação de briefing
- análise financeira operacional
- registro de decisão
- criação de proposta de tarefa

Nenhuma ferramenta pode ignorar autorização, tenant ou validação de domínio. A existência de uma tool não significa autorização automática para executá-la.
