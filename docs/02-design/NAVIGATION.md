# Navegação

A navegação deve respeitar perfil e fase disponível. O menu não substitui autorização no backend.

## Núcleo Fase 1
Dashboard, Agenda, Eventos, Espaços/Reservas, Planejamento/Checklist, Relatórios e Administração conforme perfil.

## Regra
Rotas ocultas por perfil também devem ser protegidas contra acesso direto.
