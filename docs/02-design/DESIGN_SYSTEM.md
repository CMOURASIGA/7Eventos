# Design System - Consult Services 7Eventos

## Identidade
- Consult Services como marca principal e 7Eventos como produto.
- Predominância do azul Consult Services.
- Evitar predominância roxa/índigo.
- Sidebar e navegação coerentes com 7Commander e 7Finance.

## Componentes mínimos padronizados
App Shell, Sidebar, Header, Breadcrumb, Cards, KPI Cards, Table, Button, Input, Select, Date/Time controls, Modal/Dialog, Drawer, Feedback, Skeleton, Empty State e Error State.

## Regras de UX
- Não usar `alert()` nativo para regra de negócio.
- Feedback relevante deve usar componente visual padronizado.
- Toda tela assíncrona deve prever loading, vazio e erro.
- Formulários devem apresentar validação próxima ao campo.
- Ações destrutivas exigem confirmação apropriada.
- Responsividade e acessibilidade básica são critérios de pronto.

Detalhes visuais exatos devem reutilizar os componentes existentes adequados do repositório antes da criação de novos padrões.
